# 💱 Currency Converter App (React Native)

This is a **React Native Currency Converter App** that allows users to convert Indian Rupees (INR) to various foreign currencies using predefined exchange rates.
It provides a smooth, modern UI and uses essential React Native components like `FlatList`, `TextInput`, and `Pressable`. Snackbars are used for validation feedback.

## 📦 Installation

1. **Clone the repository:**

   ```bash
   git clone <your-repository-url>
   cd <your-project-folder>
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Install required libraries:**

   ```bash
   npm install react-native-snackbar
   ```

4. **Link native dependencies (if needed):**

   ```bash
   npx react-native link
   ```

---

## ⚙️ Features

* ✅ Convert INR to multiple foreign currencies.
* ✅ Uses a clean, scrollable UI powered by **FlatList**.
* ✅ Snackbar notifications for:

  * Empty input
  * Invalid number formats
* ✅ Highlight selected currency button.
* ✅ Customizable styling with `StyleSheet`.

---

## 🛠️ Tech Stack

* **React Native**
* **JavaScript (ES6+)**
* **FlatList**
* **React Hooks** (`useState`)
* **react-native-snackbar** (for validations)

## 🧠 Learnings & Concepts Practiced

* 📐 **UI Layout** with `View`, `Text`, `TextInput`, and `FlatList`.
* 📱 Difference between **FlatList** vs **ScrollView** in terms of performance.
* 🎯 **State Management** using `useState`.
* 🎨 Styling with `StyleSheet.create()`.
* ⚠️ Real-time form **validation using Snackbar**.
* 📦 Component-based architecture (`CurrencyButton`).
* 💬 Handling user interactions with `Pressable`.
* 📏 Working with layout, flexbox, and text inputs in React Native.
* 🧪 Implementing input validation and toast-like feedback.

## 🚀 How to Run the App

* Run on Android:

  ```bash
  npx react-native run-android
  ```

* Run on iOS (MacOS required):

  ```bash
  npx react-native run-ios
  ```
